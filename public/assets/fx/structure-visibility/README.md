# FX — visibilité des Structures

Visualisation d'une Structure/Objet invisible pour l'adversaire puis
réémergente (`CardDefinition.visibleDuringTide`, trigger `onBecomeVisible`
— voir `game/cards/types.ts` et `game/environment/resolveEnvironment.ts`).
Le propriétaire voit toujours la carte ; seul l'affichage côté adversaire
change.
