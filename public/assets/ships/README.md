# Navires

Cadre Navire + médaillons + illustrations, un jeu par Navire verrouillé
(voir `game/environment/shipData.ts` — Le Courlis, L'Errant, Le
Brise-Lames).

## Assets validés (statut : validé sur Notion)

- **Cadre Navire — cadre vide** : cadre principal vertical, bois vieilli +
  laiton, cordages, médaillon-compas supérieur, zone centrale vide, plaque
  inférieure vierge.
- **Cadre Navire — médaillon Ancrage** : cercle seul, bordure laiton
  vieillie, intérieur rouge texturé, sans texte ni icône.
- **Cadre Navire — médaillon Raison** : cercle seul, bordure laiton
  vieillie, intérieur bleu texturé, sans texte ni icône.

Ces trois éléments sont la base modulaire du cadre Navire — valeurs,
icônes et textes se superposent séparément dans l'interface (pas incrustés
dans l'asset).
