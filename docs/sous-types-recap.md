# Sous-types des Marins et Créatures — récapitulatif

Validé le 09/10/2026 (206 cartes). « Affiché » : imprimé sous le type. « Porté » : tout ce que les effets peuvent viser. Un Dead, Altérés et Cavalerie sont, pour le joueur, des archétypes (écrits en bas de la carte) : leur sous-type moteur n'est pas réimprimé. Marionnette reste un sous-type imprimé ; sa troupe est l'archétype Théâtre Englouti.

## Vocabulaire

- **Familles de jeu (historiques, lues par des effets)** : Marionnette (19), Un Dead (19), Cavalerie (12), Altéré (20), Éclat (5), Objet flottant (4), Objet (3)
- **Espèces** : Volatile (8), Humain (59), Poisson (9), Amphibien (27), Squelette (1), Crustacé (2), Bête (4), Reptile (2), Monstre (9), Métahumain (20), Homme-poisson (4), Homme-bête (11), Gobelin (2), Gnome (1), Nain (1), Troll (2), Géant (2), Dragon (2), Fantôme (2), Mort-vivant (13)
- **Rôles** : Pirate (2), Chevalier (9), Gardien (1), Soigneur (6), Mage (2), Héros (16), Voleur (1), Nécromancien (1)
- **Natures** : Mécanique (2), Maudit (7), Sauvage (1), Mythique (19)

Entre parenthèses : cartes qui le portent, tous types confondus.
