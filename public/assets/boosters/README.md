# Boosters

Sachets (un dossier par extension : fermé, bande et corps ouverts) et l'écran Mes boosters.

| Fichier | Usage |
| --- | --- |
| `<id>/<id>.webp`, `<id>-open-top`, `<id>-open-bottom` | Le sachet fermé et ses deux moitiés à l'ouverture (`boosterPackVisuals.ts`) |
| `<id>/<id>-rayon.webp` | Le ROULEAU de l'étagère (nom et « x » peints ; le compte se pose à 55,6 % × 64,5 %). Manque encore : Poissons pas Frais |
| `etagere.webp` | L'étagère à six rayons ; planches à 27,2 % + n × 13,58 % de sa hauteur |
| `decor-boussoles.webp` | Boussoles, gemmes et pièces au pied de l'étagère |
| `plan-douverture.webp` | L'ancien socle d'ouverture (écran d'avant le 27/09/2026) |
