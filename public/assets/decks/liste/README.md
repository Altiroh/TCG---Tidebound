# Liste des decks — « la table » (25/09/2026)

Visuels de la nouvelle liste des decks (`features/decks/DeckTable.tsx`), convertis depuis les PNG du commit « NEW DECK LIST » :

- `fond.webp` — le livre de bord ouvert (1672 × 941).
- `onglet.webp` — bande de parchemin (onglets, tri, compteur) ; `recherche.webp` — barre de recherche sombre.
- `pile.webp` — cadre de la pile de cartes d'un deck (fenêtre : x 13–91 %, y 4–81 %).
- `bandeau-titre.webp` — le bandeau du nom sous la pile.
- `fiche.webp` — le cadre de bois de la fiche (illustration : x 12–92 %, y 7–25 % ; corps : à partir de 29 %).
- `fleche.webp` — flèche de défilement.
- `icone-mes-decks`, `icone-preconstruits`, `icone-favoris`, `icone-recemment-joues` — icônes des onglets.
- `encre-1..3.webp` — la tache d'encre qui éclot sous le deck choisi.
- Décor : `encrier`, `plume`, `bougie`, `bouteille`.
