# Collectables

La table de l'écran Collectables (`features/cosmetics/CollectablesScreen.tsx`, maquette du 26/09/2026). Chaque asset est rogné au plus près de son opaque ; les positions se lisent dans `Collectables.module.css`.

| Fichier | Usage |
| --- | --- |
| `panneau-familles.webp` | Panneau des familles, à gauche |
| `ui/bandeaux/bandeau-parchemin.webp` | Bandeau de parchemin en tête de chaque famille (étiré) — partagé |
| `ui/panneaux/fiche-epinglee.webp` | Fiche épinglée d'un objet (l'épingle occupe les 6,6 % du haut) |
| `ui/plaques/plaque-nom.webp` | Plaque du nom sous le visuel — partagée |
| `ui/boutons/plaque-bois.webp` | Plaque de bois ferrée des boutons (Équiper, Acheter) — partagée |
| `decor-gauche.webp` | Boussole, cordages et gemmes, en bas à gauche de l'écran |
| `decor-droite.webp` | Lanterne, pièces et cartes, le long du bord droit |

Le fond de table est celui de l'accueil (`ui/fonds/carte-marine.webp`).
